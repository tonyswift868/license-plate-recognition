## 运行边界与正式数据准备

正式 CCPD2019/CCPD2020 需要人工按开发文档 7.1 提供的仓库/网盘途径获取并解压；本批没有下载数据。将原始目录放在 `algorithm/data/raw/`，其下应能找到 `ccpd2019/`、`ccpd2020/`，CCPD2020 数据还需符合索引脚本识别的 `ccpd_green/` 子目录结构。解压位置、文件数、CCPD 文件名和样例图先人工抽查；若目录结构和脚本默认假设不一致，先核实数据实际布局再建索引。正式数据量大，下载、解压、索引、构建字符集和训练耗时受网络、磁盘、CPU 及实际样本数影响，本次 mock 秒数不能外推，正式首次运行应逐项计时。

仿真数据是流程夹具，像素和标签均为合成。`--allow-shortfall` 只用于本次小样本抽样；正式测试集须满足开发文档 7.4 配额，抽样命令应省略这个开关。金样例输出也只放在 `out`，本批没有建立或改写正式 golden、manifest、默认配置和 `algorithm/reports/scoreboard.md`。字体合成只用于本机 mock 训练补类别；本机 SimHei 的许可未核实。正式补字应先选择来源和许可明确、允许相应训练用途的字体，例如许可清晰的 OFL 字体，并让字体样本只进入训练集，不混入真实验证集和测试集。

```python
from pathlib import Path
import shutil

root = Path(r"algorithm/out/receipts/第三批-runbook/utf8run")
dest = root / "chars_train"
for split in ("train", "val"):
    for source_root, prefix in ((root / "chars_ccpd", "ccpd_"), (root / "chars_font", "font_")):
        for source in (source_root / split).iterdir():
            target = dest / split / source.name
            target.mkdir(parents=True, exist_ok=True)
            for image in source.glob("*.png"):
                shutil.copy2(image, target / (prefix + image.name))
print(dest)
```

### 11. 生成临时配置，跑每日 val、Top-3 和临时积分板

输入：第 2 步索引、三个 out 模型。输出：`.../utf8run/{cnn,template,svm}.toml`、`eval_{cnn,template,svm}/report.json`，以及正式积分板的临时副本 `scoreboard-copy.md`。每种 val 评测 4.493/4.552/6.075 秒；临时配置和积分板副本准备约 1.2 秒。

运行时配置只覆盖已存在的 runtime 键。以下命令生成的配置写到 out，`model_path` 是绝对路径；不改 `algorithm/config/default.toml`。

```powershell
$R = 'algorithm/out/receipts/第三批-runbook/utf8run'
$models = (Resolve-Path "$R/models").Path.Replace('\','/')
foreach ($kind in @('cnn', 'template', 'svm')) {
    $file = switch ($kind) { 'cnn' {'mock_cnn.pt'} 'template' {'mock_templates.npz'} 'svm' {'mock_svm.joblib'} }
    $toml = "[runtime]`ntorch_threads=2`nmodel_path=`"$models/$file`"`nclassifier=`"$kind`"`nmax_candidates=3`n"
    [IO.File]::WriteAllText((Join-Path $PWD "$R/$kind.toml"), $toml, [Text.UTF8Encoding]::new($false))

Copy-Item -LiteralPath algorithm/reports/scoreboard.md -Destination "$R/scoreboard-copy.md" -Force
```

### 14. 从本批 mock 图构造 G3 视频

输入：`algorithm/data/raw_mock/ccpd2019/ccpd_base/*.jpg`。输出：`.../utf8run/mock_video.mp4`，25 张图循环写成 250 帧，640×480、25 fps。耗时 **1.519 秒**。将代码保存为 `.../utf8run/make_mock_video.py` 后执行；脚本不改 raw 数据。

```python
from pathlib import Path
import cv2

images = sorted(Path("algorithm/data/raw_mock/ccpd2019/ccpd_base").glob("*.jpg"))[:25]
width, height = 640, 480
video = Path(r"algorithm/out/receipts/第三批-runbook/utf8run/mock_video.mp4")
video.parent.mkdir(parents=True, exist_ok=True)
writer = cv2.VideoWriter(str(video), cv2.VideoWriter_fourcc(*"mp4v"), 25.0, (width, height))
if not writer.isOpened():
    raise RuntimeError("MP4V writer unavailable")
for i in range(250):
    image = cv2.imread(str(images[i % len(images)]))
    writer.write(cv2.resize(image, (width, height)))
writer.release()
print(f"video={video} frames=250 fps=25 source_images={len(images)} size={width}x{height}")
```


## 数据到位后的正式测量规则

真实数据落位后从第 2 步开始重建索引，再依序审查测试集配额、金样例、字符类别覆盖和 split 隔离。正式测试 manifest 由确认过的测试样本组成，必须满足开发文档 7.4 每类数量，且训练/调参只用 train/val。正式 CNN 按 8.2 初值训练，模板/SVM按 8.3 使用真实训练字符；每次模型版本都由工具登记到输出模型目录的 manifest，确认验收后再由模型所有者决定入库。当前校准脚本会抽取全索引各 split 并报告分割计数，但几何建议只由 val 观测形成；不得根据其中测试计数选择参数。测试集用于固定报告。

每日 val 评测记录日期、commit、分类器、各有样本类别准确率、字符准确率、Top-3 定位召回、自动通过精度、G1 P95 和版本备注。正式积分板由负责人写入；本手册只演示向临时副本写一行。G1 按开发文档要求预热 5 次并计时 100 次；G2 报各类别的整牌完全匹配准确率、自动通过率/精度及 Top-3；G3 对全视频解码、按 5 fps 抽帧并计时端到端吞吐。所有结果都必须保留原始命令、环境、样本数和输出，mock 数据或短缺类别不得冒充 G1/G2/G3 正式验收。
