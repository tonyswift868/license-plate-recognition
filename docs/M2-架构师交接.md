## 9. 踩过的坑

- `algorithm/models/manifest.json` 是 **CRLF + 2 空格缩进**。两人同时登记模型会冲突：按键取并集（同键内容必须一致），写回时保持 CRLF，否则整文件都显示为改动。
- **部分覆盖的留档配置会随默认漂移**（10-28 已修）。以后新建留档配置，要写成完整快照，或至少写全所有曾改过的键。
- **员工的测试可能依赖本工位 `out/` 下的本地数据或运行目录**（01 的省份校准测试曾如此）。合入后在主检出跑全量 pytest 才能发现。
  修法：缺数据时 `pytest.skip`；路径一律写成绝对路径。
- **契约测试锁定接口**：`tests/test_contracts.py` 锁着配置键集合与关键函数签名。员工加键或参数会触发失败；确认向后兼容后由架构师同步，并记在提交里。
- **Codex 会话卡死**：界面显示“未能停止聊天”是 Codex 软件自身的问题。先确认该工位没有进程、工作区已提交，再让用户关掉重开，重开后发开场白。
- **派单里写“不许删除临时目录”**：员工删不掉，而且会花时间反复尝试。统一由架构师出清单、用户执行。
