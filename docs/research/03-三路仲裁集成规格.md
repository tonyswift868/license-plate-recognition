```text

    B = lazy_cached_box_read(candidate)  # 至多一次；需要它参与配对时才计算亦可
    for rect in candidate.rects_in_original_order:
        S, R = existing_segment_attempt(rect), existing_crnn_attempt(rect)
        for (left, right) in [(S,R), (S,B), (R,B)]:

    if B.valid and B.conf >= box_solo_min:
```

## 3. 未通过时的D0_M回退

自动OK的status、plate、confidence、route和候选/rect索引逐项保持，回退不能使任何行新增OK。先保存合法读法的路径身份，再构造以下候选；所有平分均保留先出现者。

**A（校正回退）**：遍历同rect的S/R合法同串对，按`min(S.conf,R.conf)`最高选，返回R的文字/路线/rect，输出confidence为该min；没有这种对则取所有rect中最高置信合法R；仍没有则A不存在。

**M（majority）**：按候选/rect原顺序，找首个有同串两票的rect，按S/R、S/B、R/B优先序选首对，返回左路线的文字/身份，confidence为两者min。没有两票一致时，取全体候选最高置信合法B；无B再取最高置信合法R；仍无则M不存在。三条同串仍按上述首对处理，不能改成跨rect投票或选择最高分配对。

**L（兜底旧S/R）**：独立复放当前旧S/R策略的首个OK，S/R一致阈值为`0.8225060701370239`、两个solo如第2节；旧S/R一致返回S及`max(S.conf,R.conf)`，否则solo先S再R。未旧OK时，原白黑牌错误门禁先保留；其他图优先A，没有A时保留旧仲裁的最佳合法手动S/R（每rect先S否则R，再跨rect按置信度最高稳定选择）。L这里只提供文字/身份，不能将其旧OK标志变成新OK。

```text
if no_new_auto_OK:
    A, M, L = corrected_fallback(), majority_fallback(), legacy_sr_fallback()
    Bmax = max_conf_valid_B_over_all_candidates  # 平分保持候选顺序
    if A exists and Bmax exists and Bmax.conf >= A.conf + 0.0:
        preferred = M
    else:
        preferred = A
    chosen = first_existing([preferred, A, M, L])  # 同对象不必重复检查
    if chosen exists:
        return LOW_CONFIDENCE(chosen.text, chosen.conf, chosen.route, chosen.indices)
    return internal_NO_READ
```

置信度差阈值就是`0.0`，相等走M。Bmax可能来自另一候选；A的confidence可能是S/R对的min。选中M不代表最终一定返回B，M也可能返回同rect的S或R。不要误实现成“最高B直接替换所有未OK读法”。

### 7.3 T20_A回退和稳定并列

A/M/L严格复用第3节的读法定义（M的同串对输出min置信度，A的S/R对输出R身份与min置信度，L每rect手动S优先否则R）；所有max仅严格大于才替换，同分保留原候选/rect/路线顺序。以下角度只取**融合后候选0的预测corners**，LT/RT/RB/LB原图坐标；不得用GT角点、CCPD角度/亮度或真值颜色。

```text
if new_auto_OK: return it
A, M, L = existing_fallback_choices()
q = fused_candidates[0].predicted_corners if fused_candidates else missing  # LT,RT,RB,LB
if q is four finite points:
    top = atan2(q.RT.y-q.LT.y, q.RT.x-q.LT.x) * 180/pi
    bottom = atan2(q.RB.y-q.LB.y, q.RB.x-q.LB.x) * 180/pi
    angle = (abs(top)+abs(bottom))/2
else: angle = missing
preferred = A if angle exists and angle >= 20.0 else M
chosen = first_existing([preferred, A, M, L])
if chosen: return LOW_CONFIDENCE(chosen.text, chosen.conf, chosen.route, chosen.indices)
return internal_NO_READ
```

缺候选/角点/非有限值的信号为false，走M再A/M/L，不用图像文件名或其他候选角度兜替。L旧OK在此只提供手动读法，不新增自动OK。角度是顶/底边atan2的绝对值平均，不是外接bbox长宽比或GT倾角。20.0不做额外归一到[-90,90]，以重放预测corners定义为准。

业务处理保持第4节：自动OK/BAD_INPUT先返回；无候选NO_PLATE；未自动通过且candidate0首rect white/black→UNSUPPORTED；否则保留合法手动；NO_READ保留最高旧S/R INVALID_FORMAT，仍无则SEG_FAILED。没有首rect不借顶级lead_color代替。主4个白黑非OK均使仲裁原本正确的文字不计业务正确，不能混报原始hard2008/dark50为最终业务2004/dark49。

### 7.5 p2补救、对照和选择边界

p2是评分前写定的门禁：原政策选出首个auto后，只检查该candidate/rect三条合法路线对其预测省份首字的支持，至少两条；B-solo可检查该candidate的任一单rect，不跨rect拼票。失败直接转手动，不再找下一auto。此谓词不读truth/真实省份；fit用标签检测子组风险是评测选择步骤，不进入运行时。

主fit五组均≥99，所以未采纳p2；完整集非皖225/228=98.6842%暴露风险。预写p2-011反事实fit少9、hold少9、full少18张，未减少误通过，不能在看过hold后改为新推荐。两条旧路线共同误认“皖”仍能给两票支持；此门禁不是省份风险保证。

旧定位+boxv2对照单独fit选`p2-safe-111 + M`，阈值agree `0.8672111630439758`、Bsolo `0.8627038598060608`；safe先完整遍历原000，若无auto才遍历旧SR一致/Ssolo/Rsolo，再对选中auto执行p2。fit fn107/109<99触发，p2 fit两集合995合格后采纳。该对照全量auto满足995，整牌业务val979、hard1786、dark47、tilt527，不能把对照阈值搬给主组合，也不能与架构师全量扫描原majority的978/1792直接当同政策差值。

基础二阈值及自动开关仅fit选；33回退在000上fit选一次，冻结ID应用最终auto；hold只报告，未用作再选择。固定开发图曾在先前模型分析中使用，不称整个系统独立盲测。内容安全assignment两组合相同、fit/hold原图字节交叉0。
