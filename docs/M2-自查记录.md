# M2 自查记录：CBLPRD-330k 与车牌字体

- 自查事项：开发文档 17.3 第 2 项（CBLPRD-330k 仓库及许可；车牌字体来源及许可）
- 查证日期：2026-10-24（Asia/Tokyo）
- 范围：查阅公开原始网页与本地合成脚本；未下载数据集、未下载或安装字体、未安装依赖。

## 结论

1. CBLPRD-330k 原作者仓库为 [SunlifeV/CBLPRD-330k](https://github.com/SunlifeV/CBLPRD-330k)。README 声明数据集约含 330,000 张 GAN 生成的中国车牌图像，用于训练和评估，并声明数据集按 MIT License 发布。该许可没有课程用途限制；按发布者声明的一般 MIT 授权，课程训练、评估和再分发可按 MIT 条款进行，无需另取教学用途许可，分发时保留版权与许可文本。此结论记录的是发布者的许可声明；GAN 训练素材、字体及图片底层权利链未独立核验。
2. README 列出港、澳、挂、学、领、使、临等额外字符以及 I/O，牌型包括黑色、单双层黄牌、蓝牌、拖拉机绿牌和大小型新能源。作者说明为平衡字符可能生成不符合常识的号码（例如全字母）。因此它不是本项目冻结 65 类和真实号牌规则的直接等价数据，不宜不加筛选地用于测试集或当作真实牌照分布证据。
3. 本地 [`synth_chars.py`](../algorithm/lpr_tools/train/synth_chars.py) 默认字体为 `C:/Windows/Fonts/simhei.ttf`，本机该路径存在。Microsoft 字体页将 SimHei 版权标为 Beijing ZhongYi Electronics Co.；Microsoft FAQ 区分一般图形输出与随应用/游戏使用的图像；对后一种情况，它要求图像为词、短语或段落，并明确不允许转换为逐字独立的位图字体。当前工具逐字符导出图像，不能据该 FAQ 的一般图形输出条款确定其机器学习训练样本用途获许可；专门覆盖此用途的许可未查到。此处不据此判断违法。应选择许可明确覆盖用途的 OFL 字体，或向权利方确认扩展权利；不要分发 SimHei 字体文件。
4. 可核实许可的通用中文字体 Noto Sans SC 由 Google Fonts 标为 OFL，目录附 SIL Open Font License 1.1，可按该许可条件使用及再分发。它是通用简体中文无衬线字体，不是车牌专用字形，不能称为实牌字体。
5. 本次没有查到具有可独立核实授权、可直接用于本项目的中国车牌专用字体。部分车牌生成项目标注仓库代码为 MIT 并自述含字体文件，但没有逐一给出字体资产的来源与许可；不能把代码许可自动扩展成字体文件许可。专用车牌字体的许可结论为“未查到”。

## 限制

- 仅核实查证日公开页面显示的内容；未下载或检查数据包、未逐张检查图像/元数据，也未审计 GAN 训练素材及字体来源。
- 仓库、许可页面可能变化；记录使用时应保存所用仓库版本或页面快照，并记下数据包版本/哈希。
- 字体专用许可需以字体权利方发布的具体许可为准；本次没有查到可确认授权的中国车牌专用字体。
- 合成样本只用于训练，不进入验证或测试集；合成字体数据不能替代 CCPD/实拍数据，也不能代表真实号牌识别准确率。
