## 怎么用

需要一份团队仓库的真正 clone（Gitee），在 Git Bash 里执行：

```bash
git clone <团队仓库地址> parkinglot
cd parkinglot
git checkout -b feature/lpr-integrate origin/develop
git am -3 /d/keshe2/workers/parkinglot-patches/*.patch
git push -u origin feature/lpr-integrate
```

然后在 Gitee 上从 `feature/lpr-integrate` 向 `develop` 提 PR，描述粘贴下面一节。
如果 10-30 之后组员改过 README.md、docs/TASKS.md 或 docs/api.md，`git am -3` 可能停下来提示冲突：
解决冲突后 `git add` 相应文件，再执行 `git am --continue`。

## PR 说明（可直接粘贴）

标题：`feat(lpr): 接入真实车牌识别`

### 这个 PR 做了什么

- 交付 M2b：`algorithm/lpr/pipeline.py` 的 `recognize(image_bytes) -> dict` 返回 schemas/recognition.py 的 6 个字段，并随附默认 CPU 模型。
- 入场、出场接口把 `image_base64` 解码后交给识别，用线程池调用，不卡事件循环。

识别分流规则：

| 请求 | 结果 |
| --- | --- |
| 给了车牌 | 直接用，不调算法 |
| 不给图也不给车牌 | 保留演示用的占位识别 |
| 有图，识别状态为 OK | 用识别出的车牌 |
| 有图，置信度低、没找到车牌或依赖缺失 | 返回 3001，转人工 |
